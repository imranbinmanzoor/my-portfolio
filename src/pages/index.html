instruction.md
Count the domino tilings of the 12 × 12 square.

Write the exact count to `/app/answer.txt` as a

The instruction

What the agent reads. It has to be complete, exact and written by hand.

  • Every output path appears in backticks
  • States the exact format, so nothing is left to guess
  • Says nothing about how it will be graded
  • No headings, no first-person preamble, no repeated requirements
task.toml
[metadata]
difficulty = "hard"
category = "scientific-computing"

[agent]
timeout_sec = 3600.0

[verifier]
timeout_sec = 600.0

[environment]
cpus = 2
memory_mb = 4096

Task configuration

Metadata, resources and time limits that match the real work.

  • The field matches the core work: numerical work is scientific computing, not formal mathematics
  • Time limits sized from the reference run
  • The task name matches the platform record exactly
environment/Dockerfile
FROM python:3.12-slim@sha256:<pinned digest>
RUN pip install --no-cache-dir \
      numpy==2.1.3 sympy==1.13.3
RUN mkdir -p /app
WORKDIR /app

The environment

The world the agent works in. It must build the same way every time.

  • Base image pinned by digest, packages by exact version
  • Every download checked against a checksum
  • No solution or tests inside the image
solution/solve.sh
#!/bin/bash
set -euo pipefail
python3 "$(dirname "$0")/count.py" > /app/answer.txt

The reference solution

Proof that the task can be solved, run by the platform as an oracle.

  • Scores 1 on every attempt
  • Exact integer arithmetic where the answer is exact
  • Worker pools sized from the container’s CPU limit, never os.cpu_count()
tests/test.sh
#!/bin/bash
mkdir -p /logs/verifier
echo 0 > /logs/verifier/reward.txt
if pytest --ctrf /logs/verifier/ctrf.json \
     /tests/test_outputs.py -rA; then
  echo 1 > /logs/verifier/reward.txt
fi

The verifier entry point

Runs after the agent finishes and writes the reward.

  • The reward starts at 0, so a crash can’t pass
  • pytest and pytest-json-ctrf pinned
  • Doing nothing scores 0
tests/test_outputs.py
from pathlib import Path

EXPECTED = int(Path("/tests/expected.txt").read_text())

def test_answer_is_exact():
    text = Path("/app/answer.txt").read_text().strip()
    assert text.isdigit(), "answer must be an integer"
    assert int(text) == EXPECTED

The tests

Check the result, not the method, and accept nothing vague.

  • Instructions and tests agree on every requirement
  • Extra text is rejected, not guessed at
  • Hidden from the agent until grading

The axiom audit

For proofs, passing the kernel isn’t enough. The proof must rest on standard axioms only.

  • Any sorryAx or new axiom scores 0
  • The statement comes from a sealed copy, so a submission can’t change what it proves
  • Checked in a clean build after the agent’s processes have stopped
