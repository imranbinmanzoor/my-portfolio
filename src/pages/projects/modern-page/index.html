Two forms, one interface

This project explores switching between sign-in and registration within a shared composition. It is an interface study, rather than a deployed authentication service.

What the project explores

Motion with a purpose

The transition between forms is the central visual idea. It gives the visitor a sense of moving between related states while keeping the overall interface recognisable.

Form hierarchy

Labels, fields, supporting actions, and the main button need a clear order. Working on a small interface makes those relationships easier to examine closely.

What matters in a production version

Real authentication also requires secure server-side handling, accessible error feedback, password-manager support, keyboard testing, and reduced-motion behaviour. A visual demo alone does not establish those guarantees.
