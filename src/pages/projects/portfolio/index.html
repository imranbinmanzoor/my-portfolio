A personal site with a learning library

This site brings my research contributions, frontend projects, and teaching together. The mathematics library belongs inside that wider portfolio, with focused reading and Practice views for students.

One system, several kinds of page

Shared typography, colour, navigation, spacing, and controls connect the pages. Project pages give work room to breathe; lessons use a narrower reading measure; generated papers have their own printable layout.

Built to be maintained

Authored pages, mathematical content, question banks, and shared components are kept separately. A static build generates the public site, and checks run before GitHub Pages publishes it.

Mathematics has its own quality standard

A rendered equation is not proof of correctness. Content review must check assumptions, transformations, notation, and complete reasoning separately from frontend and print testing.

A working mathematical illustration

The homepage complex-plane study connects the subject I teach with the interfaces I build. Multiplication by the imaginary unit rotates a point through a quarter turn while preserving its modulus. Its labels use the same mathematical renderer as the Class 10 book.

Still growing

One unit is currently published in each of Classes 9 and 10. Classes 11 and 12 are planned. Class 9’s original authoring source is missing; its existing mathematical SVGs are preserved while a maintainable authoring path is developed.
