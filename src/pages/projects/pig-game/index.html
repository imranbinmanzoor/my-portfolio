The Pig Game

A browser-based dice game built while learning JavaScript. A small interface for a useful programming problem: keeping game rules, application state, and the display in agreement.

A small game with visible state

Two players take turns rolling a die and deciding whether to continue or hold. The interface shows the current player, the turn score, and the accumulated scores.

What the project explores

Rules and state transitions

A roll, a hold, and a restart each change the game in a different way. The programming task is to keep those rules explicit and make the display reflect the current state.

Feedback at the right moment

The active-player treatment, dice image, and score changes help the players understand what has happened and whose turn comes next.

Learning context

This browser game is part of my JavaScript learning work. It provides a compact setting for practising event handling, conditional logic, and updating the DOM.
