A study in landing-page design

Omnifood is a fictional food subscription service. The project brings together a product introduction, meal examples, testimonials, pricing, and an enquiry form in one responsive page.

What the project explores

Hierarchy and pacing

The page moves from a broad introduction toward the details a visitor would need before signing up. Photography, headings, and section spacing give each part a distinct role.

Responsive layout

A marketing page must remain understandable as its columns rearrange. This project provided practice with CSS layout, image sizing, navigation, and form structure across screen sizes.

Learning context

This is a course-based frontend project for a fictional brand. I present it as part of my development practice, with credit to Jonas Schmedtmann’s HTML and CSS course.
